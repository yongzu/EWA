# PromptLayer — 메타프롬프팅(Meta-Prompting) 정리

원문: https://www.promptlayer.com/glossary/meta-prompting/
(원문 전체 번역이 아니라 내용을 재구성한 정리본)

## 정의

프롬프트 자체를 생성·수정·해석하는 데 다른 프롬프트를 쓰는 프롬프트 엔지니어링 기법. 특정 작업 하나에 답하는 대신, AI가 더 구체적인 하위 프롬프트를 스스로 이해하거나 만들도록 이끄는 상위 수준의 프롬프트를 설계하는 접근이다.

## 핵심 특징 5가지

1. 프롬프트 생성 — AI가 작업에 맞는 프롬프트를 만들어낸다.
2. 프롬프트 해석 — 복잡한 프롬프트 구조를 AI가 이해하고 적용하도록 이끈다.
3. 동적 적응 — 맥락이나 피드백에 따라 프롬프팅 전략을 조정한다.
4. 추상화 — 프롬프트 설계·적용을 고수준 개념으로 다룬다.
5. 자기 성찰 — AI가 자신의 프롬프팅 방식을 스스로 분석하고 개선하게 한다.

## 방법 7가지

1. 프롬프트 템플릿 생성 — 작업별 프롬프트를 만드는 틀을 설계한다.
2. 프롬프트 분석 — AI로 기존 프롬프트를 평가·개선한다.
3. 맥락 인식 프롬프팅 — 상황에 따라 프롬프트를 동적으로 조정한다.
4. 다층 프롬프팅 — 일반적인 것에서 구체적인 것까지 프롬프트 위계를 쌓는다.
5. 피드백 루프 통합 — 결과를 반영해 메타프롬프팅 전략을 다듬는다.
6. 교차 도메인 적응 — 한 도메인의 프롬프팅 원칙을 다른 도메인에 적용한다.
7. 자기 수정 프롬프트 — 초기 응답을 바탕으로 스스로 조정되는 프롬프트를 만든다.

## 장점 5가지

- 범용성: 더 넓은 범위의 작업을 효과적으로 처리
- 자율성: AI가 새 과제에 더 자기주도적으로 대응
- 자원 효율: 프롬프트 생성·적용 과정 최적화
- 확장성: 다양하고 계속 변하는 문제 영역에 적용 용이
- 지속적 학습: 프롬프팅·문제해결 능력의 지속적 개선 지원

## 과제(한계) 5가지

- 복잡성 관리: 메타프롬프트의 정교함과 사용성 사이 균형
- 해석 가능성: 메타프롬프팅 과정이 이해·통제 가능한 상태를 유지해야 함
- 오류 전파: 여러 층을 거치며 오류·편향이 증폭될 위험
- 계산 오버헤드: 다층 프롬프팅에 따른 처리 부담 증가 가능성
- 윤리적 고려사항: 점점 자율적인 AI 시스템의 책임 있는 사용 확보

## 베스트 프랙티스 8가지

1. 명확한 위계 설정 — 메타프롬프트 안의 추상화 단계를 분명히 정의
2. 모듈화 — 재사용·조합 가능한 구성요소로 설계
3. 충분한 테스트 — 다양한 시나리오·작업에서 엄격히 검증
4. 피드백 통합 — 성능 피드백을 반영해 전략을 다듬음
5. 투명성 — 과정과 판단 근거를 문서로 명확히 남김
6. 윤리 지침 — 설계·적용 단계에서 윤리 원칙 수립·준수
7. 사용자 통제 — 사람이 감독·개입할 수 있는 장치 마련
8. 지속적 평가 — 전략의 효과성과 적절성을 정기적으로 재점검

## 예시 구조 (원문 예시를 개념만 재구성)

"[특정 주제]를 분석하는 프롬프트를 만들어라. 그 프롬프트는 (1) 핵심 요약 (2) 주요 논점 파악 (3) 근거 평가 (4) 추가 조사 방향 제안을 포함해야 한다"는 식의, 하위 프롬프트를 생성하도록 지시하는 상위 프롬프트 하나가 예시로 제시된다. 구체적 논문이나 도구명은 등장하지 않고, 일반화된 형태의 예시 하나뿐이다.
